# הקופסה · אפליקציה נלווית ל־Mafia de Cuba

אפליקציה נלווית למשחק Mafia de Cuba, למשחק פנים אל פנים. כל שחקן משתמש בטלפון שלו במקום הקופסה, היהלומים והטוקנים. החקירה עצמה נשארת בקול סביב השולחן.

- 5–12 שחקנים, בלי הרשמה ובלי חשבונות.
- המארח פותח שולחן, והשאר מצטרפים עם קוד בן 4 ספרות או ברקוד.
- הטלפון של המארח מחזיק את מצב המשחק, והטלפונים מתחברים אליו ישירות (WebRTC דרך PeerJS). לכן המארח צריך להשאיר את האפליקציה פתוחה. כשהמארח סוגר את השולחן מהתפריט, כל השחקנים מקבלים "השולחן נסגר" מיד. אם הוא פשוט מתנתק, זה קורה אחרי כדקה בלי חיבור (כך שרענון דף או נתק קצר לא מפילים את המשחק).

## קבצים
- `game.js` – כל חוקי המשחק (פונקציה טהורה). בדיקות: `node test/game.test.mjs`
- `sync.js` – סנכרון בין הטלפונים (P2P; גם Firebase אופציונלי דרך `config.js`)
- `app.js`, `style.css`, `index.html` – הממשק
- `?local=1` – מצב בדיקה בלשוניות של דפדפן אחד
- `?solo=6` – מצב בדיקה בלשונית אחת: 5–12 שחקנים יושבים אוטומטית, ופס בתחתית (או המקשים 1–9, 0) מחליף בין הטלפונים

## משפטי
אפליקציה לא רשמית וללא מטרות רווח, ללא קשר ל־Lui-même או למחברי המשחק. Mafia de Cuba הוא שם מסחרי של בעליו. כדי לשחק צריך עותק של המשחק. החוקים באפליקציה מנוסחים מחדש בקיצור, והאיורים מקוריים.

ספריות צד שלישי ורישיונותיהן: `THIRD_PARTY_LICENSES.md`.
